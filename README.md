# 애견국비 — Meta 광고 카드뉴스 시안

한국반려동물전문학원 (경남 양산) · 반려동물행동지도사 2급 국비지원 과정 · 11월 개강

## 여는 법
**`index.html`** 더블클릭 → 16개 시안 목록에서 골라 여세요.
각 파일은 사진·로고까지 전부 품은 **독립 실행 파일**입니다. 하나만 따로 보내도 그대로 열립니다.
(권장 브라우저: Chrome)

## 강아지 사진은 흐름에 맞춰 3장만

7장 중 **후킹(1장) · 학원 소개(6장) · 마무리 상담(7장)** 에만 들어갑니다.
자격 설명 · 교육비 · 목록 카드는 정보 전달에 집중하도록 사진을 뺐습니다.

`img/dog1~9.webp` — 모두 **배경 제거 컷아웃**이라 색 배경 위에 바로 올라갑니다.

| 파일 | 내용 | 성격 |
|---|---|---|
| `dog1` | 손 신호 받는 골든 | 훈련·전문성 |
| `dog2` | 뛰어오는 골든 퍼피 | 발랄·시작 |
| `dog3` | 앉은 래브라도 + 쓰다듬는 손 | 신뢰·교감 |
| `dog4` | 코에 손 대는 강아지 | 따뜻함 |
| `dog5` | 발 잡은 손 (악수) | 약속·마무리 |
| `dog6` | 달려오는 골든 | 활기 |
| `dog7` | 달리는 폭스테리어 | 귀여움 |
| `dog8` | 엎드린 골든 퍼피 | 귀여움·아이 |
| `dog9` | 강아지 4마리 | 다양성 |

## 글자 고치는 법
파일을 텍스트 편집기로 열면 위쪽에 **`const CARDS = [...]`** 가 있습니다.
한글만 고치고 저장 → 브라우저 새로고침하면 바로 반영됩니다.

- `**별표 두 개**` = 강조 ｜ `왼쪽 | 오른쪽` = 세로줄로 좌우 구분
- `note` 는 과장광고 방지 안전 문구입니다. **지우지 마세요**
- `★확인필요` = 학원 확인 후 교체할 자리
- `dog` 는 `dog1`~`dog9` 중 하나 (비우면 사진 없음)

## 전체 재생성
사진이나 카피를 한꺼번에 바꿀 때만 사용하세요.
```
python3 _src/build.py
```
⚠️ 실행하면 16개 HTML이 **덮어쓰기** 됩니다. HTML을 직접 고쳤다면 실행하지 마세요.
새 강아지 사진은 `img/dogN.webp` 로 같은 이름으로 덮어쓰면 됩니다.

## PNG 저장
상단 **전체 PNG 저장** → `타깃_시안N_01.png` … 순서로 저장 (2160×2160)
Chrome에서 "여러 파일 다운로드 허용"을 눌러주세요.

정부 후원·승인·인증으로 읽히는 문구와 함께 쓰지 마세요.
